# Movie Review Sentiment Analysis Using CNN-LSTM

## Project Overview
This project uses Deep Learning to classify movie reviews into two categories: Positive and Negative.

It combines Convolutional Neural Networks (CNN) and Long Short-Term Memory (LSTM) networks using TensorFlow and Keras.

## Objectives
- Analyse movie reviews using Deep Learning.
- Understand CNN and LSTM architectures.
- Train a sentiment classification model.
- Predict the sentiment of new movie reviews.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Google Colab

## Dataset
IMDB Movie Reviews Dataset containing 50,000 labelled movie reviews.

## Model Architecture
Input → Embedding → CNN → MaxPooling → LSTM → Dropout → Dense

## Working
1. Load the movie review dataset.
2. Preprocess and pad the text sequences.
3. Build the CNN-LSTM model.
4. Train the model.
5. Evaluate its accuracy.
6. Predict positive or negative sentiment.

## Expected Output
The model predicts whether a given movie review expresses a positive or negative opinion.
